# План развития

Цель на ближайшие ~2 недели: больше трафика из поиска и больше пользователей. Поэтому сначала исправляем то, что мешает индексации и подрывает обещание «файлы остаются у вас», потом закладываем фундамент качества, потом добавляем востребованные инструменты.

Решения, принятые при планировании:

- Языки пока только ru и en.
- Аналитика: Vercel Web Analytics и Speed Insights (без cookies). Яндекс.Метрику не ставим, она противоречит обещанию приватности.
- Свой домен будет куплен. До покупки всё работает на `*.vercel.app`.
- Модели OCR раздаём со своего домена, без сторонних CDN.
- «Закрасить навсегда» делаем через растеризацию страниц.
- «PDF в Word» выдаёт текст с абзацами (.txt и .docx), без сохранения вёрстки.

Состояние на 26.09.2026: тесты, lint, typecheck и сборка проходят, `npm audit` уязвимостей не находит. Этапы 0, 1 и 2 выполнены (кроме шагов после покупки домена).

## Этап 0. Срочные исправления (1–2 дня)

- [x] **0.1. Растеризация не удаляет старый текст.** [rasterize.ts:33-35](src/lib/pdf/rasterize.ts#L33-L35) вставляет новую страницу и удаляет старую, но `removePage` только убирает её из дерева страниц. Content stream старой страницы остаётся в файле, и `save()` его записывает. Проверено: строка `SECRET PASSPORT 1234` находится в итоговом PDF. Опция «Растрировать страницы с правками текста» и README обещают обратное.
  - Исправление: собирать результат в новый документ (`PDFDocument.create()` + `copyPages`, как в [pages.ts](src/lib/pdf/pages.ts)) или после замены страниц удалять из `context` объекты, недостижимые от trailer.
  - Регрессионный тест: после растеризации исходная строка не находится ни в одном потоке файла.
  - Без этого исправления нельзя делать «Закрасить навсегда» (п. 3.5).
- [x] **0.2. hreflang и Open Graph на страницах инструментов указывают на главную.** `toolMetadata` ([ToolPage.tsx:29](src/components/ToolPage.tsx#L29)) возвращает только title и description, остальное наследуется из [layout.tsx:27](src/app/[locale]/layout.tsx#L27). Сейчас в HTML `/ru/merge` стоит `hreflang="ru" → /ru`, `og:title` взят с главной, `canonical` нет. Поисковик видит 13 страниц как альтернативы главной.
  - Исправление: в `toolMetadata` задать `alternates.canonical`, `alternates.languages` (включая `x-default`) и `openGraph` с URL, заголовком и описанием самого инструмента. У главной тоже проставить canonical.
- [x] **0.3. `npm run lint` падает (10 ошибок и 1733 предупреждения).** Все они в сгенерированной папке `public/pdfjs`, в `src/` и `tests/` ошибок нет. Добавить `public/pdfjs/**` (и позже `public/tesseract/**`) в `globalIgnores` в [eslint.config.mjs](eslint.config.mjs).
- [x] **0.4. Расшифрованный PDF сохраняется в черновик.** Автосохранение ([autosave.ts:61](src/features/editor/autosave.ts#L61)) кладёт в IndexedDB уже расшифрованные байты. Если пользователь открыл запароленный файл на чужом компьютере, файл остаётся там без пароля. Для `source.wasEncrypted` черновик не сохранять (или сохранять только после явного согласия).

Итоги этапа 2:

- Нашлась ещё одна проблема: редактор рендерится только в браузере, поэтому у страниц редактора (`/editor`, `/sign`, `/edit-text`, `/fill-form`) в HTML не было ни заголовка, ни текста. Теперь заголовок, инструкция и вопросы рендерятся на сервере и прячутся, когда открыт файл.
- Старые адреса `/editor?tool=…` постоянным редиректом ведут на новые страницы.
- Тексты FAQ проверены автором. Разметка FAQPage строится из тех же данных, что видны на странице, это проверяет тест. Google с 2023 года показывает расширенные FAQ-сниппеты почти только сайтам госорганов и медицины, но разметка всё равно помогает поисковикам понять страницу.
- Картинки для превью рисуются при сборке (28 штук). Иконки lucide-react в них отрисовываются через данные SVG, потому что сами компоненты клиентские.

## Этап 3. Новые инструменты (6–8 дней)

Порядок: сначала дешёвые инструменты с высоким спросом, в конце самые трудоёмкие. Если сроки поплывут, в бэклог уходит конец списка. Для каждого инструмента нужны запись в [tools.ts](src/lib/tools.ts), страница, переводы, FAQ из п. 2.2 и тест в `tests/`.

- [ ] **3.1. Номера страниц** (~0,5–1 день). 6 позиций, формат `{n}` или `{n} из {total}`, начальный номер, диапазон страниц (переиспользовать [ranges.ts](src/lib/pdf/ranges.ts)), шрифт с кириллицей из [fonts.ts](src/lib/pdf/fonts.ts). Общую логику «нанести что-то на все страницы с учётом поворота» вынести в `lib/pdf/stamp.ts`.
- [ ] **3.2. Водяной знак** (~1 день). Текст или картинка; размер, цвет, прозрачность, угол, режим «по центру» или «плиткой». Построить на том же `stamp.ts`. Превью на миниатюре первой страницы.
- [ ] **3.3. Свойства файла** (~0,5 дня). Показать и изменить Title, Author, Subject, Keywords, Creator, Producer и даты. Кнопка «Удалить все метаданные» должна удалять и XMP-поток `/Metadata` из каталога: сеттеры pdf-lib его не трогают.
- [ ] **3.4. Чёрно-белый PDF** (~1–1,5 дня). Картинки переводить в DeviceGray через уже существующий конвейер сжатия ([compress.ts](src/lib/pdf/compress.ts)), цветовые операторы в content streams (`rg`/`RG`/`k`/`K`/`sc`) заменять на серые. Для страниц, которые не удалось обработать, запасной вариант: растеризация в оттенках серого.
- [ ] **3.5. Закрасить навсегда** (~1,5–2 дня, только после п. 0.1). Режим `redact` в редакторе: рисование прямоугольников, как у `whiteout`. При экспорте страницы с закраской растеризуются, аннотации и поля форм под закраской удаляются, по желанию добавляется OCR-слой, чтобы вернуть поиск по остальному тексту, и очищаются метаданные (п. 3.3). Отдельная посадочная страница `/redact` (п. 2.1). Тест: закрытый текст не находится в байтах файла.
- [ ] **3.6. PDF в Word и текст** (~2–3 дня).
  - Текст брать из `getTextContent` pdf.js, группировку в строки взять из [textLines.ts](src/features/editor/textLines.ts).
  - Строки склеивать в абзацы по вертикальным отступам и отступу первой строки. Заголовки определять по размеру шрифта, жирный и курсив по имени шрифта.
  - .docx собирать вручную из минимального WordprocessingML и упаковывать уже подключённым `fflate`, без новой зависимости.
  - Для сканов без текстового слоя предлагать OCR (переиспользовать `runOcr`).
  - На странице честно написать, что таблицы и колонки не сохраняются.
