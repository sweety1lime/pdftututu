# pdftutut

Надоело, что все онлайн-редакторы PDF просят регистрацию или подписку, поэтому сделал свой. Всё работает прямо в браузере, файлы никуда не загружаются.

## Что умеет

- редактировать PDF: добавить текст, поправить уже существующий, вставить картинку или подпись, нарисовать фигуры, выделить маркером
- заполнять формы
- объединять и разделять файлы
- поворачивать, удалять и переставлять страницы
- делать PDF из картинок и картинки из PDF
- сжимать
- ставить и снимать пароль
- распознавать текст на сканах (OCR)

Есть тёмная тема и английский язык.

## Как запустить у себя

Нужен Node.js 20 или новее.

```
npm install
npm run dev
```

Потом открыть http://localhost:3000

Ещё команды:

- `npm run build` собрать проект
- `npm test` прогнать тесты
- `npm run e2e` прогнать сценарии в браузере (Playwright, нужен `npm run build`; браузер ставится командой `npx playwright install chromium`)
- `npm run lint` проверить код

Всё это же запускается на GitHub при каждом пуше в main и в пулреквестах.

## Деплой

Сайт живёт на Vercel. Подключаешь репозиторий, жмёшь Deploy, больше ничего настраивать не надо. Дальше каждый пуш в main обновляет сайт сам.

## На чём сделано

Next.js, TypeScript, Tailwind. Страницы рисует pdf.js, сами файлы меняет pdf-lib (форк @cantoo/pdf-lib, в нём есть шифрование). Редактор на Konva, OCR через tesseract.js.

Шрифты PT Sans, PT Serif и PT Mono лежат в `public/fonts`. Без них в PDF нельзя писать по-русски.

## Что пока не очень

- Правка текста работает так: старая строка закрашивается, а сверху пишется новая. Старый текст при этом остаётся в файле. Если нужно убрать его совсем, при скачивании включи «Растрировать страницы с правками текста».
- XFA-формы не поддерживаются.
